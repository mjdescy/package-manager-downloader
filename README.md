# downloader

A test repository to set up one piece of a larger package manager that I am building as a learning project with my son.

## Overview

This repo is a small, standalone piece that will eventually be put into the package manager project. It is meant to download a package file or folder from a URL and save the file to a local filesystem location.

## Usage

```sh
cargo run -- download <source-url> <destination-path>
```

## Status

Work in progress. This is an early scaffold intended to validate the structure
and tooling before building out the full downloader functionality.
